Remover senha de planilha do Excel sem saber a senha

Sabe quando você abre uma planilha e não consegue editar nada porque está protegida, e você não sabe a senha? Neste tutorial eu te mostro como remover essa proteção editando diretamente o XML interno do arquivo — sem precisar de programas especiais e sem saber a senha.

Importante: este método funciona apenas para proteção de planilha (aquela que impede editar células, formatar, etc.). NÃO funciona para senha de abertura (quando o Excel pede senha antes mesmo de abrir o arquivo).

📋 Passo a passo completo

Passo 1: Faça um backup do arquivo (obrigatório)

Clique com o botão direito no arquivo Excel → escolha "Copiar" → cole na mesma pasta para gerar uma cópia (ex.: Planilha - Cópia.xlsx). Todas as etapas seguintes devem ser feitas apenas na cópia, garantindo que o arquivo original permaneça intacto.

Passo 2: Ative a exibição das extensões de arquivo

O Windows 11 oculta as extensões por padrão. Para exibi-las:

  • Abra o Explorador de Arquivos;
  • Clique em "Exibir" no menu superior;
  • Escolha "Mostrar";
  • Marque "Extensões de nomes de arquivos".

Passo 3: Renomeie o .xlsx para .zip

Clique com o botão direito na cópia → Renomear → altere a extensão final de .xlsx para .zip → pressione Enter. O Windows exibirá um aviso dizendo que "alterar a extensão pode tornar o arquivo inutilizável". Clique em "Sim" para continuar.

Passo 4: Abra o ZIP e localize o arquivo da planilha

Dê um duplo clique no arquivo .zip (ou clique com o botão direito e escolha abrir com um compactador). Navegue pela seguinte estrutura de pastas:

xl → worksheets

Você verá arquivos como sheet1.xml, sheet2.xml, etc. Cada um corresponde a uma aba da planilha. Se não souber qual aba está protegida, teste uma por uma.

Passo 5: Edite o arquivo XML

Forma recomendada: editar diretamente com o 7-Zip (evita erros).

Abra o arquivo ZIP com o 7-Zip, clique com o botão direito em sheet1.xml → escolha "Editar". O arquivo abrirá no Bloco de Notas. Pressione Ctrl + F e pesquise por:

sheetProtection

Você encontrará uma tag parecida com esta:

<sheetProtection algorithmName="SHA-512" hashValue="..." saltValue="..." spinCount="100000" sheet="1" objects="1" scenarios="1"/>

Selecione todo o trecho, desde <sheetProtection até />, e apague com a tecla Delete. Atenção: apague apenas esse trecho, sem remover o código ao redor.

Passo 6: Salve e restaure o formato do arquivo

Salve o arquivo XML. Feche a janela do compactador (se o 7-Zip perguntar se deseja atualizar o arquivo compactado, escolha "Sim"). Por fim, renomeie o arquivo de .zip de volta para .xlsx e confirme o aviso. Abra o arquivo no Excel — a proteção da planilha deve ter sido removida.

🔍 Observações complementares

Se encontrar <workbookProtection> em vez de <sheetProtection>: isso significa que a proteção é de estrutura da pasta de trabalho (impede adicionar, excluir ou renomear abas). Nesse caso, o arquivo a ser editado é o xl\workbook.xml, e você deve apagar essa tag também.

Se o arquivo apresentar erro de "arquivo corrompido" ao abrir: provavelmente houve exclusão a mais ou a menos durante a edição. Recomenda-se apagar a cópia atual, criar uma nova a partir do original e refazer o processo. Evite descompactar e recompactar manualmente — isso costuma causar problemas na estrutura interna do arquivo.
